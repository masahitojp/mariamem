## 正しさと制約

- 恒久テストは折り返し、短い読み、部分書込、複数ライター、Closeでの解除、writer Close後の排出とEOFを検査。実際のProcessで両方向の満杯を観測してからキャンセル、切断原因でのAbort、完読後のShutdownと資源解放を検査した。対象テスト8回、リング単体race検査15回が通った。
- 実ホストの別ビルドでは実際のwriterが満杯待ちに入ったところで、各方向のクライアント切断、通信中のServer.Close、キャンセル、応答完読後の正常終了を各6回確認。厳密な追加テスト60例のうち54例成功。残り6例は未完の入力Callに内部Shutdownを重ねた場合のEOF。診断失敗をそのまま保存した。同じ16 KiB送信点に合わせた対照では、OS・リングとも6/6回で保留中のCallがEOF、Shutdown成功、処分完了。これは未完の内部Callの扱いで、公開の同期Closeは上記の全例で完了した。[厳密な結果](faults.log) · [OS対照](partial-baseline.log) · [製品候補](partial-candidate.log)
- Go 1.26.11で daily の生成物検査、Go単体・vet、Python、公開境界、および smoke のSQL、Live、同一プロセスの接続、Fork・再Snapshotを完走した。ローカルはmacOS arm64で実施した。[daily](daily.log) · [smoke](smoke.log) · [再現手順](REPRODUCE.md)
